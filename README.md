# Macro Lens

FRED 공식 API를 이용해 미국 금리, 물가, 고용, 성장, 유동성 지표를 보여주는 반응형 투자 대시보드입니다. API 키는 서버에서만 사용되며 브라우저에 노출되지 않습니다.

## 실행

1. `.env` 파일에 발급받은 FRED API 키를 입력합니다.

```dotenv
FRED_API_KEY=발급받은_API_KEY
```

2. Node.js 18 이상에서 서버를 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```powershell
npm start
```

3. 브라우저에서 `http://127.0.0.1:4173`을 엽니다.

키가 없거나 FRED 연결에 실패하면 화면은 내장 샘플 데이터를 표시합니다. `.env`는 `.gitignore`에 포함되어 있으므로 커밋되지 않습니다.

## 주요 기능

- 14개 FRED 핵심 지표 공식 API 연동
- API 키를 숨기는 서버 프록시와 15분 메모리 캐시
- 금리·물가·경기·유동성 카테고리 필터
- 지표별 기간 선택 상세 차트
- 성장·물가·위험 기반 매크로 신호 요약
- 최근 36개월 주요 지표 Pearson 상관관계 매트릭스와 비교 차트
- 모바일 반응형 레이아웃
